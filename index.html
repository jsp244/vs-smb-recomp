VS. Super Mario Bros. native port

Nintendo's 1986 arcade game, VS. Super Mario Bros., as a native program for Windows, Linux, the Steam Deck and Android. Its 6502 program is statically recompiled into C and runs on a small runtime that recreates the Vs. System board.

Download the latest release Source code on GitHub

No game data is included. You need your own dump of the VS. Super Mario Bros. board: an iNES .nes file, or MAME's suprmrio.zip. The program checks its hash and refuses anything else.

What you get

  • The cabinet as it was. Coin slot, 1P and 2P start, and the board's DIP switches: free play (the default) or coins and credits, lives, coins for an extra life, timer speed and lives after a continue.
  • Arcade colours. The Vs. board's RGB palette as the cabinet's monitor showed it, or the NES console's colours.
  • Widescreen. In 16:9 and 16:10 the level carries on beside the picture during play, with the enemies the game keeps there, and Mario can walk into it.
  • Super Mario All-Stars graphics and music (optional). With your own SNES Super Mario All-Stars ROM, the game can look and sound like All-Stars' Super Mario Bros., drawn and played by All-Stars' own code in a small SNES sandbox. Nothing from that ROM is saved.
  • Save states, rewind and fast-forward. Nine slots, several minutes of rewind, and run-ahead to cancel the game's own input lag.
  • Display options. Integer, fit or stretch scaling, scanline and CRT shaders, and an unlimited sprite mode with no flicker.
  • Keyboard and gamepad. Every button can be rebound. In a two-player game the players take turns on one pad, as on the NES.
  • Built-in updates. The Updates tab asks GitHub for a newer release only when you press it, and checks the download's SHA-256 before installing it.

Getting started

  1. Run vssmb.exe on Windows or vssmb on Linux. On the Steam Deck follow STEAMDECK.txt; on Android install the APK and open it.
  2. On the ROM tab choose Choose ROM file... and pick your .nes or .zip file, or drop it onto the window.
  3. Go to Play > Start game. The chosen file is remembered.
  4. The cabinet starts on its PUSH BUTTON screen: press Start for one player (the 2 key starts a two-player game).

Player guides: Windows and Linux, Steam Deck, Android.

How it is made

A recompiler (recomp/recomp.py) translates the arcade's 6502 program into C ahead of time. The C is linked against a small runtime written for this project: the Vs. System's PPU with its RGB palette, the APU, the board's mapper, the coin slots and the DIP switches, plus an interpreter for any code the recompiler did not reach. The graphics, music and level data are read from your dump when the program starts, and the repository holds no game data or game code. Details are in the README and the architecture notes.

The recompiler, runtime and frontend are open source under the MIT licence. The SNES sound unit behind the All-Stars music is LakeSnes's emulation (MIT licence).
