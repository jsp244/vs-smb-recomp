; Address labels for VS. Super Mario Bros. Format: ADDR name [hook]. Lines starting with ; are ignored.
; A label starting with JumpEngine marks a routine that jumps through the word table after its JSR.
; "hook": the generated code calls the runtime (sys.hook) just before that instruction runs.
; These are annotations written for this project; they contain no game data.
8000 reset
810A nmi
81FE irq
90BB JumpEngine
965C InitializeArea hook   ; an area starts (from its halfway or entrance page too); widescreen.c re-runs it a page earlier
ADAB GameEngine hook   ; the frame's object logic and sprite building; widescreen.c re-runs it beside the screen
A2D7 AreaParserCore hook   ; one metatile column of the level; allstars.c parses the same column with All-Stars' parser
